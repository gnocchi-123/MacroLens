## 1. 목적과 현재 상태

이 문서는 미국 11개 섹터를 네 거시 요인으로 점수화하기 전에, **어떤 경제적 가설로 계수를 정했고 무엇이 그 가설을 깨뜨릴 수 있는지** 기록한다. 실제 수익률에서 추정한 계수가 아니다. 문헌에 나온 계수를 복사한 것도 아니다. 아래 숫자는 검증할 규칙을 구체화한 자체 제안이다.

첨부한 `MacroLens_Project_Context_v2.txt`와 `macro_sector_project_plan_v2.md`의 3~5절 및 개발 단계 3을 기준으로 작성했다. 사용자가 M2 완료를 알린 상태에서 M3 문서 작업을 시작한다. 첨부 계획의 옛 구현 상태를 현재 상태로 되돌려 적용하지 않는다. 이번 작업에서는 저장소·M2 코드·병합 상태를 직접 점검하지 않았다.

| 구분 | 이번 문서의 상태 |
| --- | --- |
| 섹터별 가설·계수 제안 | 11개 섹터, 44개 조합 작성 |
| 경제적 참고 자료 | 공식 데이터 설명·원저자 연구·기관 자체 설명 확인 |
| 정확한 계수의 경험적 근거 | 없음. 모두 정성 가설 또는 판단 유보 |
| 전체 계수 동결 | 미완료. 검토 후 버전·설정·시점을 함께 고정 |
| 프로그램 반영·실제 점수 | 미실행 |
| 예측력·투자 성과 검증 | 미실행. M4에서 수행 |

M1·M2의 가상 섹터와 실행 확인용 계수는 그대로 보존한다. 이번 표가 구현되더라도 표시는 **“실제 거시 자료 / 연구용 가설 계수 / 미검증”**이다. 실제 자료를 쓴다는 사실이 계수 검증을 뜻하지 않는다.

## 2. 무엇을 예측하려는가

주된 가설은 “현재 이용 가능한 거시 자료로 계산한 점수가 높을수록, 이후 3개월의 섹터 상대 성과가 좋다”이다. 주간 판단, 3개월 주평가, 1개월·6개월 보조 평가는 기존 계획을 따른다.

점수는 섹터 간 비교를 위한 환경 적합도다. 절대 주가 상승률·상승 확률·기업 이익 전망치가 아니다. 방어적 섹터의 성장 계수가 음수인 것은 성장 둔화 때 **상대적인 선호가 높아진다**는 가설이며, 경기 침체가 그 기업의 매출을 늘린다는 주장이 아니다.

이 모델은 경기 국면을 네 단계로 직접 분류하지 않는다. 경기순환 문헌을 참고하되 연속형 요인을 고정 계수로 합산한다. 국면별 성과 관찰을 개별 요인의 독립적인 인과효과로 바꾸어 해석하지 않는다.

## 3. 네 입력의 정확한 뜻

아래 식에서 m은 판단 시점에 이용 가능한 최신 월별 관측, d는 최신 일별 관측이다. 모든 과거 값도 판단 시점에 이용 가능한 동일한 자료 버전 규칙으로 선택한다.

| 표시명 / 식별자 | 원자료와 변환 x | 표준화 요인 F가 양수인 뜻 | 대용 지표의 한계 |
| --- | --- | --- | --- |
| 성장 / `growth` | INDPRO: `100 × (IP_m / IP_(m-12) - 1)` | 산업생산 전년 대비 증가율이 과거 기준보다 높음 | 산업생산은 제조·광업·유틸리티를 포함하지만 서비스 경제 전체나 세계 수요를 대표하지 못함 [S3] |
| 고용 / `employment` | UNRATE: `-(U_m - U_(m-3))`, 단위 %포인트 | 실업률 3개월 변화의 역방향 값이 과거 기준보다 높음 | 고용자 수·임금·노동참가율을 직접 측정하지 않음 [S4] |
| 물가 / `inflation` | CPIAUCSL: `100 × (CPI_m / CPI_(m-12) - 1)` | 소비자물가 전년 대비 상승률이 과거 기준보다 높음 | 기업 투입비용·원유가격·시장 예상 대비 물가 충격과 다름 [S5] |
| 금리 / `rates` | DGS10: `y_d - y_d0`, d0는 `d-28일` 이하 최신 유효 관측일 | 10년 명목 국채금리의 28일 변화가 과거 기준보다 높음 | 기준금리 수준·실질금리·장단기 금리 차이·신용 스프레드와 다름 [S6] |

금리는 28개 거래일이 아니라 **28개 달력일**을 사용한다. 금리 차이의 단위는 %포인트이며, 금리의 퍼센트 변화율이 아니다. 기존 M2 코드가 다른 기준일을 사용한다면 구현 전에 차이를 명시하고 결정한다. 조용히 변환을 바꾸지 않는다.

각 변환값은 최신 관측을 제외한 이전 유효 관측으로 표준화한다.

```text
z = (최신 변환값 - 과거 변환값 평균) / 과거 변환값 표본 표준편차
F = clip(z, -3, +3) / 3
표본 표준편차: ddof=1
```

이 후보의 표준화 창 제안은 월별 세 지표 각각 60개, 일별 DGS10 변환값 1,260개다. 주별 260개는 주별 입력을 따로 도입할 때의 후보이며 일별 창과 혼용하지 않는다. 필요한 변환 준비 기간을 추가 확보한다. M2가 이미 다른 창을 고정했다면 그 차이를 검토하고 모델 버전에 반영한 뒤 동결한다.

F의 양수는 절대적인 호황·고용 증가·금리 상승과 같지 않다. 금리가 하락했어도 과거 평균보다 덜 하락했다면 금리 F는 양수일 수 있다. 보고서에는 원자료, 변환값, F를 함께 표시한다.

월별 값을 매주 복제해 새 관측으로 세지 않는다. 네 입력 중 하나라도 유효성을 잃으면 전체 공식 비교 순위를 보류한다. 개별 섹터의 계수가 0이라는 이유로 모델 전체의 입력 검사를 생략하지 않는다. 지연 허용치·시점 정책은 기존 설정을 확인한 후 동결 묶음에 포함한다.

## 4. 근거를 사용하는 방식

다음 자료들은 경제적 경로와 모델의 한계를 설명한다. **어느 자료도 이 문서의 44개 숫자나 3개월 예측력을 검증하지 않는다.**

| 근거 ID | 확인한 내용 | 이 모델로 옮길 때의 제한 |
| --- | --- | --- |
| S1 | MSCI의 GICS 체계는 11개 섹터를 구분하고 분류 변경을 관리함 | 분류 기준이지 투자 추천이나 계수표가 아님 |
| S2 | Fidelity는 경기 국면별 섹터 성과 차이와 방어적 수요를 설명함 | 역사적 국면 분석이지 현재 네 요인의 회귀분석이 아님 |
| S3~S6 | FRED의 지표 정의·단위·빈도 | 데이터 정의의 근거이며 수익 예측력의 근거가 아님 |
| S7 | Bernanke·Kuttner는 예상하지 못한 통화정책 변화와 주식가격 반응을 연구함 | 정책 서프라이즈 연구를 DGS10의 28일 변화 계수로 직접 전용할 수 없음 |
| S8 | FDIC는 대출수익률과 조달비용이 은행 순이자마진에 함께 작용함을 보여줌 | 은행에 관한 자료를 금융 섹터 전체의 고정 양수 금리 계수로 일반화하지 않음 |
| S9 | Nareit는 성장 개선이 금리 상승과 REIT 실적 개선에 함께 연결될 수 있음을 설명함 | 금리 상승 = 부동산 하락이라는 단순 규칙의 반대 근거. 산업단체 자료임 |
| S10 | EIA는 원유가격에 세계 수급·공급 차질 등이 작용함을 설명함 | 미국 CPI만으로 에너지 판매가격·이익을 설명할 수 없음 |

근거 수준은 다음처럼 표기한다.

- **정성:** 경제 경로를 바탕으로 연구자가 방향과 비중을 제안했다. 통계적으로 확인한 방향이 아니다.
- **약함:** 입력이 해당 경로의 간접 대용 지표이거나 반대 경로가 커서 특히 불확실하다.
- **유보:** 고정 방향을 채택할 충분한 근거가 없어 0으로 설정한다. 실제 영향이 0이라는 추정이 아니다.

표의 출처는 ‘경로 참고’ 또는 ‘한계·반대 근거’로 연결한다. 특정 출처가 숫자를 제안했다고 읽어서는 안 된다. 모든 계수의 크기 선택은 MacroLens 자체 설계다.

## 5. 계수 선택 규칙과 전체 표

| 값 | 설계상 의미 |
| --- | --- |
| +2 / -2 | 같은 섹터 안에서 그 경로에 기본 경로의 두 배 비중을 부여 |
| +1 / -1 | 방향을 채택하되 기본 비중으로 반영 |
| 0 | 상쇄·대용 지표 부족·중복 우려로 해당 직접 기여를 사용하지 않음 |

2는 “실제 영향이 정확히 두 배” 또는 “확신도가 두 배”라는 의미가 아니다. 네 경로의 우선순위를 단순하게 표현하는 미검증 선택이다. 2를 사용하는 이유는 아래 개별 근거에 적었다. 섹터끼리 계수 크기를 직접 비교하지 않고, 정규화 후 비중을 함께 본다.

**아래 열 순서는 성장 → 고용 → 물가 → 금리다. 코드에서는 열 위치보다 식별자 이름으로 대응시킨다.**

## 6. 44개 섹터·요인 조합의 근거

이 절의 모든 행은 작성일 **2026-10-08**, 모델 후보 **`macro-sector-hypothesis-v0.1`**을 공유한다. 행 ID는 향후 설정의 `rationale_id`로 연결할 수 있다. 비중은 `|b| / D`이며 부호는 계수 열에 표시한다. 아래 내용은 문헌의 직접 결론이 아니라 참고 자료를 바탕으로 세운 **MacroLens의 가설·유보 판단**이다.

### 6.1 에너지

가설: 산업 수요와 물가 압력이 함께 높을 때 상대적인 환경 점수가 높아진다. 다만 원유·가스가격이 없어 현재 네 입력으로 설명하기 특히 어려운 섹터다.

| ID / 요인 | 계수 / 비중 | 채택 경로 또는 유보 이유 | 반대 근거·적용 한계 | 참고 / 수준 |
| --- | --- | --- | --- | --- |
| EN-G 성장 | +1 / 50% | 생산 확대와 에너지 수요의 연결을 제한적으로 반영 | 미국 생산 확대가 에너지 공급 증가일 수도 있고 세계 수요는 별개 | S3·S10 경로/한계 / 약함 |
| EN-E 고용 | 0 / 0% | 실업률 변화로 에너지 판매가격을 판단하기 어려워 직접 반영 유보 | 고용 개선이 운송 수요를 늘릴 가능성은 남음 | S4·S10 한계 / 유보 |
| EN-I 물가 | +1 / 50% | 에너지 가격이 포함된 물가 상승을 판매가격 여건의 간접 신호로 가정 | 주거·서비스 물가 상승이나 기저효과이면 에너지 기업에 호재가 아님 | S5·S10 경로/한계 / 약함 |
| EN-R 금리 | 0 / 0% | 할인율 부담과 성장 기대가 상쇄될 수 있어 방향 유보 | 차입비용·달러 변화는 실제로 중요할 수 있음 | S6·S7·S10 한계 / 유보 |

물가 +1은 높은 확신을 뜻하지 않는다. D=2이므로 실제로는 절반의 비중을 차지한다. CPI를 에너지 가격의 대용 지표로 쓰는 선택을 이 후보의 주요 취약점으로 기록한다.

### 6.2 소재

가설: 산업생산과 원자재 판매가격 여건이 상대 성과에 유리하게 작용한다.

| ID / 요인 | 계수 / 비중 | 채택 경로 또는 유보 이유 | 반대 근거·적용 한계 | 참고 / 수준 |
| --- | --- | --- | --- | --- |
| MA-G 성장 | +2 / 50% | 생산에 투입되는 소재 수요를 핵심 경로로 정해 두 배 비중 | 해외 수요·재고·공급 증가가 국내 생산 신호를 압도할 수 있음 | S3 경로 / 정성 |
| MA-E 고용 | 0 / 0% | 성장과의 중복 및 수요와 인건비의 반대 효과로 유보 | 주택·소비 수요 경로를 놓칠 수 있음 | S3·S4 한계 / 유보 |
| MA-I 물가 | +1 / 25% | 판매가격 전가가 가능한 기업에 유리하다는 제한적 가설 | 소재 기업도 에너지·원료 구매자이며 CPI는 소재 판매가격이 아님 | S5·S10 한계 / 약함 |
| MA-R 금리 | -1 / 25% | 차입·재고 보유·투자비용 부담을 기본 비중으로 반영 | 수요 개선을 동반한 금리 상승은 호재가 더 클 수 있음 | S6·S7 한계 / 약함 |

## 7. 점수 계산과 해석

계획 v2의 산식을 유지한다.

```text
D_s = Σ |b_s,k|
C_s,k = 50 × b_s,k × F_k / D_s
S_s = 50 + Σ C_s,k
```

F가 -1~+1이고 D가 양수이면 점수는 0~100이다. `50 + 기여도 합 = 점수`를 만족해야 한다. 전주 비교도 같은 모델에서 기여도 변화 합과 점수 변화가 일치해야 한다.

**계산 확인용 가상 예시 — 실제 경제 자료나 투자 결과가 아님**

산업재 계수 `(2, 1, -1, -1)`에 요인 `(0.6, 0.3, 0.2, 0.3)`을 넣으면 D=5다.

| 요인 | 기여도 |
| --- | ---: |
| 성장 | +12점 |
| 고용 | +3점 |
| 물가 | -2점 |
| 금리 | -3점 |
| 합계 | +10점 |
| 최종 점수 | 60점 |

60점은 상승 확률 60%가 아니다. 계수를 같은 배수로 확대해도 점수는 변하지 않는다. 0으로 유보한 항목이 많으면 나머지 항목의 정규화 비중이 커진다. 따라서 0을 선택하는 것도 실질적인 모델 결정이다.

다음은 다른 요인은 모두 0으로 놓은 계산 방향 점검이다. **경제 충격의 수익률 시뮬레이션이 아니다.**

| 섹터 | 모든 F=0 | 성장 F만 +0.6 | 금리 F만 +0.6 |
| --- | ---: | ---: | ---: |
| 에너지 | 50 | 65 | 50 |
| 소재 | 50 | 65 | 42.5 |
| 산업재 | 50 | 62 | 44 |
| 경기소비재 | 50 | 56 | 44 |
| 필수소비재 | 50 | 42.5 | 42.5 |
| 헬스케어 | 50 | 35 | 35 |
| 금융 | 50 | 65 | 50 |
| 정보기술 | 50 | 70 | 40 |
| 커뮤니케이션 서비스 | 50 | 60 | 40 |
| 유틸리티 | 50 | 40 | 30 |
| 부동산 | 50 | 57.5 | 35 |

모든 요인이 0이면 전 섹터가 동점이다. 동점 순위는 평균 순위를 기본 제안으로 하고 표시 순서만 GICS 코드 오름차순으로 고정한다. 표시 순서를 우열로 해석하지 않는다. 상·하위 3개 경계에 동점이 있으면 동점 그룹에 남은 자리의 비중을 균등 배분하는 방식 등을 M4 평가 규칙에 사전 고정한다.

## 8. 이 후보가 실패할 수 있는 이유

1. **거시 자료는 이미 가격에 반영되었을 수 있다.** 수준·변화와 시장 예상 대비 충격은 다르다. S7의 정책 서프라이즈 결과가 이 모델의 예측력을 보장하지 않는다.
2. **현재 상태와 앞으로의 변화를 혼동할 수 있다.** 높은 산업생산 증가율이 경기 정점과 겹칠 수도 있다. 이 모델에는 경기 전환점 예측이나 가속도 항이 없다.
3. **요인 중복이 있다.** 성장과 고용, 물가와 명목금리가 상관되어 같은 상황을 여러 번 반영할 수 있다. 고정 계수는 이 중복을 통계적으로 제거하지 않는다.
4. **선형·대칭 가정이 강하다.** F가 +0.5일 때의 기여와 -0.5일 때의 기여는 정확히 반대다. 고물가와 디플레이션이 모두 불리한 비선형 관계를 표현하지 못한다.
5. **지표와 섹터가 잘 맞지 않을 수 있다.** 미국 산업생산은 서비스·세계 수요, CPI는 원자재 판매가격, DGS10은 기업 조달비용을 완전히 대변하지 않는다.
6. **정규화가 불확실성을 줄여주지 않는다.** 적은 수의 약한 가설만 남아도 합계 비중은 100%가 된다. 점수가 극단적이라고 근거가 강한 것은 아니다.
7. **구성·제도·기업별 차이를 놓친다.** 섹터 내 대형 기업 비중, 해외 노출, 규제·세금·기술 변화가 거시 요인보다 중요할 수 있다.
8. **과거 자료의 시점 한계가 남는다.** M2의 입력 재현은 당시 장중 이용 가능성을 완벽히 입증하지 않는다. 기존 `strict_point_in_time=false` 같은 한계 표시를 계수 변경만으로 해제하지 않는다.

약한 항목을 좋은 성과가 나올 때까지 반복 조정하지 않는다. 특히 EN-I, MA-I, HC-R, UT-R, RE-R은 초기 검토의 우선 대상이다. 변경하면 이유·버전·이미 본 결과를 남긴다.

## 9. M4에서 가설을 검증하는 방법

### 9.1 평가 대상과 기준

점수 작성 시점 이후 처음 가능한 미국 정규장 종가를 평가 시작 가격의 기본안으로 삼는다. 시작 이후 3개 달력월이 지난 날짜가 휴장일이면 다음 거래일 종가를 종료 가격으로 쓰는 안을 제안한다. 1개월·6개월도 같은 규칙을 적용한다. 이 날짜 규칙은 가격 자료·기존 구현을 확인한 후 결과를 보기 전에 확정한다.

배당·분할을 일관되게 반영한 총수익률로 평가한다. 섹터별 상대 수익률을 정의할 때는 같은 기간 11개 섹터 총수익률의 단순 평균을 차감하는 진단 기준을 사용할 수 있다. 이는 거래비용을 반영한 동일 비중 운용 전략의 성과와는 별도다.

| 질문 | 사전 제안 측정 방법 | 해석 |
| --- | --- | --- |
| 점수 순위가 이후 성과 순위와 연결되는가? | 매 판단 시점 11개 점수와 3개월 총수익률의 Spearman 순위상관 | 주평가. 양수가 예상 방향이며 통계적 불확실성도 보고 |
| 높은 점수와 낮은 점수의 차이가 있는가? | 상위 3개와 하위 3개 평균 총수익률 차이 | 진단용. 공매도 운용을 뜻하지 않음 |
| 거시 점수를 추가할 가치가 있는가? | 같은 대상·체결·W/M/C·비용의 동일 비중 전략과 비교 | SPY 대비 성과만으로 거시 판단을 검증하지 않음 |
| 간단한 가격 정보보다 도움이 되는가? | 사전 고정한 가격 추세 규칙과 비교 | 포트폴리오 집중도 차이를 별도 설명 |
| 각 부호가 지나치게 취약한가? | 섹터 상대 수익률과 해당 요인의 관계 및 한 요인 제외 진단 | 상관은 인과·독립 효과가 아님. 수정 근거 탐색에만 사용 |

3개월 후 수익률은 아직 확정되지 않은 사례를 학습·판정에 넣지 않는다. 주간 판단의 3개월 성과는 서로 겹치므로 독립 표본 수로 세지 않는다. 블록 재표본화 등 시간 의존성을 반영할 방법을 정한다.

### 9.2 결과를 보고 판단하는 원칙

초기 판정 제안은 다음과 같다. 통계적 유의수준·최소 관측 기간·재표본화 설정·개발/검증/최종 날짜는 데이터 가용성을 확인한 후 **성과를 보기 전에** M4 실험 명세에서 확정한다. 현재 완성된 합격 기준이라고 주장하지 않는다.

- 주평가 구간에서 순위상관과 상·하위 차이가 반대 방향이면 수정 필요로 본다.
- 방향이 양수라도 불확실성이 크거나 소수 시기·섹터에 의존하면 보류한다.
- 순위 관계가 좋아도 비용 차감 후 효용이 없으면 예측 신호와 투자 적용 결론을 구분한다.
- 한두 섹터의 좋은 결과로 전체 44개 계수를 검증했다고 표현하지 않는다.
- 실제 충격기를 제거하지 않고 최대 낙폭·회복·비용 증가·한 거래일 지연에 대한 민감도를 함께 본다.

주후보는 이 표 하나다. 요인 제외 진단을 실시한다면 네 번의 추가 시도도 기록하고 최종 구간에서 가장 좋은 변형만 고르지 않는다. 통계 추정형 계수·추가 지표·국면별 계수는 후속 후보로 분리한다.

## 10. 동결과 구현으로 넘기는 절차

### 10.1 이번 초안에서 검토할 세 가지

1. **상대 성과를 설명하는 계수라는 해석:** 방어적 섹터의 음수 성장·고용 계수를 이 목적에 맞게 받아들일 것인가?
2. **불확실한 방향의 0 처리:** 금융의 금리, 여러 섹터의 물가처럼 단일 지표로 판단하기 어려운 조합을 유보하는가?
3. **정규화 후 비중:** 에너지의 물가 50%, 정보기술의 성장 2/3, 유틸리티의 금리 2/3 같은 비중이 첫 실험 가설로 적절한가?

이 검토는 과거 수익률에서 가장 잘 맞는 숫자를 고르는 작업이 아니다. 설명 가능한 첫 가설을 고정하는 작업이다.

### 10.2 동결 기록

검토가 끝나면 아래 기록을 함께 남긴다. 아직 값이 없는 필드는 임의로 채우지 않는다.

### 10.3 M3 구현 완료 조건

- 기존 `src/macrolens` 구조와 실제 설정 방식을 먼저 확인한다. 계획 문서의 예시 경로를 근거로 새 패키지를 중복 생성하지 않는다.
- M1·M2 가상 모델과 11개 섹터 연구 모델의 식별자·출력을 분리한다.
- 11개 고유 섹터, 네 요인, 44개 계수·근거 ID를 검증한다. 허용 계수 범위와 D>0을 확인한다.
- 모든 유효 입력에서 0~100, 기여도 합, 손계산 예시, 결측 보류, 동점 처리, 같은 입력의 재현을 확인한다.
- 계수·설정 해시와 모델 버전을 실행 이력에 저장한다. 구모델과 신모델 결과의 차이를 전부 경제 변화로 표현하지 않는다.
- 보고서에 “미검증 연구용”과 시점 자료의 한계를 유지한다.

위 조건을 만족하면 M3의 계산 구현을 완료할 수 있다. 수익 예측력이나 투자 효용의 검증 완료는 M4 이후의 별도 판단이다.
