# Codex 전달서 — KIS 선택적 연결과 M1~M3 호환

작성: 2026-10-18. 아래는 당시 구현 요청 원문이다. 2026-10-23 조회 전용 구현·모의 검증을 완료했으며 실제 API 인증·수집은 미실시다. 최신 명령은 README, 계약과 한계는 kis_integration_plan.md 11절을 따른다.

## 판단

현재 M1 수집/계산은 FRED·sample, M2는 저장 실행·비교·replay, M3는 동결 모델을 사용한다.
`cli.configuration`의 모델 설정은 `config_hash`로 저장되고 `history.compare_loaded`가 이 해시를 비교한다.
따라서 KIS 인증 설정을 이 구조에 섞으면 경제 모델이 같아도 비교가 불필요하게 막힐 수 있다.
KIS는 M4 가격 모듈에 분리하며 M1~M3 계산 규칙 변경은 필요하지 않다.

| 단계 | 유지할 것 | Codex가 확인·보완할 것 |
| --- | --- | --- |
| M1 | 4개 FRED 지표·변환·샘플·기존 weekly 명령 | KIS 키/네트워크/선택 패키지 없이 기존 실행 가능. 수집기 import에서 인증하지 않음 |
| M2 | 기존 저장 형식·run_id·비교·오프라인 replay | 가격 수집/검수 ID는 별도 저장하고 후속 평가에서 macro run_id와 연결. 기존 config_hash·과거 기록을 변경하지 않음 |
| M3 | 11섹터·44계수·표준화·동점·누락·동결 설정/근거서 | KIS 티커/거래소 매핑은 가격 설정에 분리. 가격 누락은 성과평가 보류이며 유효한 거시 점수 계산은 유지 |

`config.py`의 첫 문장 '실제 연구용 섹터 계수는 아직 없다'는 전체 프로젝트 기준으로는 오래된 주석이다.
필요하다면 'M1 데모 설정이며 연구 모델은 research 모듈에서 별도 로드한다'로 설명만 정정한다.
이는 계산 변경 사유가 아니며 이번 문서 작업에서 코드는 수정하지 않았다.

## Codex에게 전달할 요청

MacroLens의 docs/kis_integration_plan.md, docs/progress.md, plan/context 2.1과 M4 문서를 읽고 기존 작업 상태를 확인해줘.
한국투자증권 API는 나중에 내가 키를 입력해서 연결할 예정이니, 지금은 키 없이 진행 가능한 선택적 연결 구조와 오프라인 검증을 준비해줘.

1. KIS를 M4 가격·권리 모듈로 분리하고 기본 비활성으로 둬. 기존 FRED·sample·history·compare·replay·report가 KIS 키 없이 작동하도록 해줘.
2. M1의 지표·변환, M2의 기존 저장 형식·비교·config_hash·재현, M3의 동결 설정·44계수·근거서 해시를 보존해줘. 불필요한 재작성은 하지 마.
3. KIS 설정은 별도로 관리하고 KIS_APP_KEY/KIS_APP_SECRET을 나중에 환경변수/Secrets로 등록할 수 있게 해줘. 실제 KIS 작업을 선택할 때만 설정 검사·인증을 해줘. 비밀값·토큰은 Git/로그/모델 해시에서 제외해줘.
4. Yahoo형 가격 계약과 분리한 KIS 어댑터를 준비하고, 최신 공식 요청/응답 계약을 확인해줘. 원본·출처·수집 시각·조정 의미·권리·해시를 보존해줘.
5. 모의 응답으로 페이지 반복/누락/중복·배당/분할 이중 처리·키 없음·오프라인 재검수를 확인해줘. 합성 결과를 실제 시장 검수로 표시하지 마.
6. 기존 FRED/sample와 M2 재현, M3 동결 해시의 회귀 검증을 하고 실제 실행한 결과만 보고해줘. 실제 API 시험은 내가 연결할 때 별도로 진행해줘.
7. 구현 완료 후 키 등록→환경 반영→연결 확인→XLC·XLK·SPY 검수→12종 확대 순서를 README에 안내해줘. 실제로 구현한 명령만 제시하고 비밀번호·키를 대화에 요구하지 마.
8. 변경 파일·이유·테스트 결과·남은 실제 검증을 한국어로 설명하고 별도 작업 브랜치에 커밋해줘. main 병합과 주문/계좌 연결은 별도 작업으로 남겨줘.

## 사용자가 나중에 할 일

- 연결 기능 구현 후 Open API 신청·키 발급을 본인 계정에서 진행한다.
- App Key/App Secret을 Codespaces Secrets 등 지정된 위치에 직접 등록한다.
- 구현자가 제공한 명령으로 연결을 확인한다. 2026-10-23 구현 명령은 README의 KIS 절을 따른다.
- 실제 가격 적격성 관문이 통과된 후 M4의 성과 계산으로 넘어간다.
