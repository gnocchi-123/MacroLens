# M3 첫 연구 모델 동결 기록

- 모델: `macro-sector-hypothesis-v1`; CLI 선택명: `research-v1`.
- 상태: 첫 검증용 규칙 동결. 경제적 가설·투자 효용은 미검증.
- 기준 코드: M2 병합 `bd50590b0c0e610466ee7673247c3aa588139d50`.
- 설정 원본: `src/macrolens/models/research_v1.json` (설치 패키지에 포함).
- 근거: `docs/model_card.md`의 44개 행. 원래 0.1 초안은 변경하지 않고 보존한다.
- 동결 시각·초안 SHA-256은 설정에 기록. 동결 커밋은 이 파일과 설정을 처음 추가한 Git 커밋이다.
- 초안의 미동결 표시는 작성 당시 상태이며, 이 기록이 v1의 채택 상태를 정한다.
- 계수 44개는 초안과 동일하다. 유보 0은 영향 없음이라는 추정이 아니다.
- M2 대조: 월별 60개·일별 1,260개, ddof=1, 최신값 제외, ±3 제한,
  28개 달력일 차이는 동일하다. M2의 28일 전 기준값 최대 7일 공백 제한도 유지한다.
- 관측 나이 한도: 월별 75일·일별 7일. 공식 발표 달력이 아닌 기존 잠정 규칙이다.
- 시점 정책: 현재 수집/과거 vintage/샘플의 M2 정책을 그대로 보존한다.
  `strict_point_in_time=false`를 유지한다.
- 순위: 연구 모델은 평균 순위, 동점 표시 순서는 GICS 코드 오름차순.
  demo-v1은 M2의 경쟁 순위(1,1,3)를 유지한다. 반올림 전 정확히 같은 점수만 동점이다.
- 이번 작업에서는 가격 자료·수익률·백테스트를 조회하거나 계수를 최적화하지 않았다.
  참고 문헌의 역사적 설명은 읽었으므로 경제 가설의 착안까지 맹검이었다고 주장하지 않는다.
  사용자가 이전에 살펴본 성과 이력은 확인되지 않았다.
- M4의 평가 기간·최소 표본·통계 설정·동점 경계 처리·합격 기준은 별도 사전 동결 대상이다.
- 계수 또는 계산·자료 이용 규칙 변경은 새 버전으로 기록한다. 이 v1 파일을 수정해 덮어쓰지 않는다.
