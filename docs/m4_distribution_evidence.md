# M4 공식 분배 근거 조사·원장 연결 (2026-11-08)

## 범위와 현재 판정

2020-06-01~2026-09-30의 XLC·XLK·SPY만 조사했다. 기존 원장을 재구현하거나 KIS를 다시
수집하지 않았다. 현재 작업 기준은 `feat/m4-kis-data`의 `cfa84aa`였고 미커밋 변경은 없었다.
관련 원격 M4 가격 기준은 `feat/m4-validation`의 `c77cbad`, KIS 계획은
`docs/kis-integration-plan`의 `6331d97`이다. 오래된 main을 구현 기준으로 바꾸지 않았다.

**직접 조사로 2025년 빈 자본이득 셀 18개를 해소했다.** 각 상품 6개다. 이는 빈칸의 일반적
정의를 찾은 것이 아니라, 같은 사건의 다른 공식 명세에서 단기·장기 분배액의 명시적 0을
확인한 결과다. 다른 연도, 다른 ETF, 주당 기준, 전체 가격 적격성으로 확대하지 않는다.

세 상품 모두 요청 전체 기간의 총수익률은 보류다. 이 환경에는 사용자 KIS archive가 없어
실제 가격 원장 실행은 **미실시**다. 부분 구간도 가격 기준·주당 기준 등이 미확인이므로
실제 계산 가능 구간으로 확정하지 않았다. 불명확한 사건을 건너뛰어 수익률을 연결하지 않는다.

## 공식 근거와 적용 범위

### D1: ETF Historical Distributions XLSX와 정의 페이지

- 문서: [SPDR ETF Historical Distributions][history], [SSGA ETF Funds Dividend Distributions][definitions].
- 대상: 세 ETF의 목표 기간 78건. XLSX는 기존 저장본, 정의 페이지 확인일은 2026-11-07.
- 위치: XLSX `dividend` 시트의 열 이름과 말미 정의, 웹페이지의 Dividend distributions 설명.
- 직접 확인: dividend는 보유 증권의 배당·이자 순수익, capital gains distribution은 증권 매각의
  순이익으로 설명된다. XLSX는 1개 시트이며 댓글 XML이 없다. 공유 문자열과 웹페이지를 읽었지만
  **빈칸이 0이라는 정의와 과거 배당을 분할 후 주수로 재표시하는 규칙은 찾지 못했다.**
- 이 미발견을 공급자의 비제공 선언으로 해석하지 않는다. 일반적인 빈칸→0 규칙을 만들지 않는다.

### D2: SPDR ETF 2025 Tax Summary — Primary Layout

- 문서: [SPDR ETF 2025 Tax Summary - Primary Layout][primary]. 확인일 2026-11-08.
- 보고일 셀B4는 2026-01-20, 시트는 `2025 ICI Primary`.
- SHA256: `16e471468cd1a66729837234c280799264232318bdb4b0928d6f7844b45bc3b0`.
- 대상: **2025년 각 상품의 4개 사건만**. CUSIP은 XLC81369Y852, XLK81369Y803, SPY78462F103.
- 확정 자료로 판단한 근거: 2025년의 사후 세무 분류 명세이고, 대상 행의 열D `Estimated (E)`에
  추정 표시가 없다. 2026년 예상 분배표와 다르다. 이후 정정 가능성을 부정하지 않으며 확인한
  원문의 해시를 고정한다.
- 열 정의 위치: 11~13행. G기준일, H배당락일, I지급일, J `Total Distribution Per Share`,
  N `Income Dividends`, O **Short-term Capital Gain**, V **Total Capital Gain Distr. / Box 2a**.
  O와 V를 각각 확인했다. 장기 자본이득 열만으로 단기 금액을 추정하지 않았다.

## 배당 주당 기준 조사와 확보하지 못한 자료

XLK 2025-03-24/06-23/09-22(분할 전)와 12-22(분할 후)를 D1과 D2의 동일 사건으로 연결했다.
D2의 J와 D1 배당금의 최대 절댓값 차이는 3×10^-17 USD였다. XLC는 2×10^-17, SPY는 1×10^-16이다.
이는 XLSX 숫자 표현을 포함한 관측값이지 원문 수정 허용 오차가 아니다. 교체·평균·반올림 보정하지 않았다.
두 자료 모두 현재 확보한 사후 파일이므로 **분할 전 발행된 당시 공식 공지와의 대조는 아니다.**
2배/절반에 가까운지만 보고 주당 기준을 결정하지 않았다.

- 특히 2025-09-22 사건을 명시한 분할 전 발행의 XLK 공식 배당 공지를 이번에 확보하지 못했다.
  검색에 제3자 배당 공지는 나왔으나 운용사 원문 대신 사용하지 않았다.
- 2020~2024년의 최종 Primary 명세 또는 사건별 확정 공지도 미확보다. 공식 상품 페이지의 Primary
  링크와 검색 결과는 현재 2025년 파일을 가리켰다. 연도별 경로 후보3개는404, tax-center 후보 페이지는
  일반 Resources 페이지로 연결돼 연도별 명세를 얻지 못했다. **그 연도 자료가 없다고 단정하지 않는다.**
- Google 응답은 JavaScript 안내 화면이었고, 추가 DuckDuckGo 검색은 도중부터 HTTP202 확인 페이지였다.
  검색 경로 제약과 자료 자체의 결함을 구분했고 제한을 우회하지 않았다.
- 새 조사 원문과 URL·시각·HTTP 상태·해시는 개인용 `data/m4_distribution_evidence/20261107/`에 저장했다.
  폴더명은 시작일이며 각 `.source.json`에는 실제 2026-11-07/08 수집 시각이 있다. 공개 Git에는 넣지 않는다.

## 기존 원장에 연결한 방식

- `src/macrolens/evidence/ssga_distribution_v1.json`은 조사 결론·대상 사건·출처 메타데이터다.
  원본 XLSX/PDF나 가격 자료를 재배포하지 않으며, 비영 배당금도 이 목록에 수록하지 않는다.
- `distribution_evidence.py`는 상품·CUSIP·배당락일·기준일·지급일을 모두 정확히 대조한다.
  문서 연도/기간, 확정 사건 여부, 추정 표시, 열 정의, 셀 위치도 검사한다. 연도만 맞거나 연간 총액인
  근거는 적용하지 않는다. 장기 열로 단기 입력을 해소할 수 없다.
- 원본 사건을 바꾸지 않고 `source_events`와 `events`(확인한 해석을 적용한 계산용 입력)를 분리한다.
  원래 `source_amounts`의 null도 남는다. 해석에는 원값·유효값·근거ID·문서ID·셀을 저장한다.
- 공식 자료끼리 또는 원값과 충돌하면 보류한다. 비영 세무 분류를 추가 현금으로 사용하지 않는다.
  같은 0을 확인하는 근거가 여러 개여도 해석 하나이며 배당 사건이나 현금을 늘리지 않는다.
- 기존 `kis ledger`가 동봉 근거 목록을 기본으로 읽고 결과 폴더에 사본·해시를 보존한다.
  네트워크 호출이나 문서 재다운로드는 하지 않는다. 근거 원문의 진위를 매 실행 때 새로 인증하지 않는다.
- 가격/주당 기준의 기존 `--review-file`과 구분한다. 이번 목록은 3개 기간 조건과 주당 기준을 해제하지
  않으며 실행만으로 원본 held/conditional도 변경하지 않는다.
- 배당락 미수금→지급 현금→지급일 뒤 첫 거래일 재투자, 분할1회, XLC 결측 규칙은 유지한다.
  M3 동결, strict_point_in_time=false, R-001 후속을 유지하며 전략 백테스트는 하지 않는다.

새 CLI의 검증된 사용법은 README에 기록한다.

## XLK 2025 우선 자료 검증 결과 (2026-11-08)

**2025년 전체는 보류이며, 실제 계산 가능하다고 확정한 부분 구간도 없다.** 가격 원본이 이 환경에
없어 실제 원장은 미실시다. 아래는 공식 자료의 직접 확인과 사용자 가격 보고를 구분한 결과다.
2025년은 자료 검증 범위다. 원래 가격 준비 구간 2020-06-01~2026-09-30과 평가 시작 후보
2021-06-07, 원장 규칙 `etf-cash-receivable-v1`은 변경하지 않는다.

### 배당 4건과 주당 기준

기존 D1 XLSX와 D2의 XLK/CUSIP `81369Y803` 사건을 오프라인으로 다시 대조했다.
새 다운로드·연간 총액 배분 없이 기존 사건별 명시 0 해석을 사용했다.

| 배당락일 = 기준일 | 지급일 | 12-05 분할과의 관계 | D2 셀 | 단기·장기 분배 | 배당의 주당 기준 |
| --- | --- | --- | --- | --- | --- |
| 2025-03-24 | 2025-03-26 | 분할 전 | O917 / V917 | 각각 명시 0 | unknown |
| 2025-06-23 | 2025-06-25 | 분할 전 | O918 / V918 | 각각 명시 0 | unknown |
| 2025-09-22 | 2025-09-24 | 분할 전 | O919 / V919 | 각각 명시 0 | unknown |
| 2025-12-22 | 2025-12-24 | 분할 후 | O920 / V920 | 각각 명시 0 | unknown |

분할 전 3건의 빈 셀 6개는 해소됐고, 12월의 원래 0 두 개는 재확인됐다.
단기·장기 빈 값은 이 4건에 더 이상 남지 않는다. 현재 이력표와 사후 세무표의 금액 일치는
분할 이전에 발행된 당시 공지와의 대조가 아니다. **2:1 공지나 Form 8937로 배당을 두 배/절반으로
바꾸지 않았으며, 분할 후 12월 사건도 발생 순서만으로 주당 기준을 승인하지 않았다.**

이번 확인 경로 `https://www.sectorspdrs.com/mainfund/XLK`는 현재 State Street XLK 상품 페이지로
이동했다(HTTP200). 기존 이력·Primary·Form8937 링크를 확인했지만, 대상 배당일의 당시 공지나
과거 배당의 소급 표시 정책은 확보하지 못했다. 이 경로를 반복 조회하지 않는다.
이것은 해당 자료가 존재하지 않는다는 확인이 아니다.

실행한 공식 파일 검수: `data/kis_distribution_evidence/20261108T111233Z-cedda721b9b7/report.md`.
XLK 2025년 사건4, 해소 빈 셀6, 남은 단기0/장기0, 주당 기준 미확인4, 충돌0이다.
기존 명령은 세 상품을 함께 표시하지만 이번 판단 범위는 XLK다. 가격 원장/총수익률 실행은 아니다.

### MODP=0 사용 근거: 공식 옵션 정의와 실제 저장본을 구분

- **직접 확인한 새 근거:** 한국투자증권 공식 `chk_dailyprice.py`, 커밋
  `3a9be59a3ed8745720dc3aa9d584bdf3b7830362`, [Parameters 57행 및 COLUMN_MAPPING][kis-option].
  57행은 `수정주가반영여부 (0 : 미반영 1 : 반영)`, 28행은 `clos: 종가`, 55행은 `GUBN=0: 일`이다.
  확인일 2026-11-08, SHA256 `ea386811dfadb5d37314aefbbf39b541298b364ecb04ce83ac245f39906ff51c`.
  MODP=0을 미수정 종가 후보로 선택할 공식 근거다. MODP=1의 배당 조정 정의는 여기서 확인되지 않는다.
- 문서의 적용 대상은 `dailyprice` API의 요청 옵션/필드다. 문서 확인일이나 코드 커밋을 실제 가격의
  관측일·거래 세션·역사 제공 기간으로 전용하지 않는다. `clos`가 정규장 마감을 뜻하는 구체적 설명과
  저장된 기간 전체의 당시 가격 여부는 이 파일만으로 확인되지 않는다.
- **사용자 제공 가격 진단:** 2025-12-04→05의 MODP=0 비율 `0.5036589136633799`, 공식2를 적용한
  진단값 `1.0073178273267598`, MODP=1 비율 `1.0073173174210168`. 이 사건에서는 미수정 가격과
  수량2배가 정합적이다. 실제 원본을 이 환경에서 읽거나 재검증한 결과가 아니며 기간 전체 승인도 아니다.
- KIS 문서 포털의 확인 경로는 HTTP404였다. 공식 GitHub 예제 파일은 HTTP200으로 확보했다.
  포털 접근 실패와 정의 미제공을 구분한다. 원문/시각/URL/해시는 Git 제외
  `data/m4_xlk_2025/20261108/`에 보존했다. KIS 인증·시장가격 호출은 0회다.

기존 원장은 이제 `result.json.price_contract_reference`에 위 출처를,
`symbols.XLK.price_contract_evidence`에 해당 구간 사용 후보 종가의 원본 페이지·해시를 연결한다.
저장 요청의 endpoint/path/TR ID/상품/거래소/GUBN/MODP가 모두 맞아야
`matched_archived_requests`다. 다른 상품·MODP=1·주봉·누락/중복 메타데이터는 일치로 표시하지 않는다.
이는 **요청 옵션의 연결 상태**다. `price_basis` 근거서, 사건 주당 기준, 원본 품질 판정을 해제하지 않는다.
배당액을 수정하거나 새 현금을 만들지 않고 기존 분할 진단과 산술을 그대로 둔다.

### 판단이 바뀌는 정확한 조건과 조사 종료점

| 차단 입력 | 현재 확인 범위 | 다음에 필요한 사실 |
| --- | --- | --- |
| 03-24·06-23·09-22의 `share_basis` | 현재 이력과 사후 ICI의 동일 사건 금액만 대조 | 각 사건 당시 공식 공지의 당시 1주당 금액과 현재 이력의 대조, 또는 이 세 사건에 적용되는 공식 소급 표시 정책. 한 사건의 확인을 나머지에 확대하지 않음 |
| 12-22의 `share_basis` | 분할 후 사건임과 현재 두 자료 일치 | 그 사건의 공지가 분할 후 당시 1주당 지급액임을 명시하거나, 해당 사건을 포함하는 공식 이력표의 주당 표시 정의 |
| 2025 구간 `price_basis` | MODP=0 미수정/clos 종가라는 공식 정의, 사용자 보고의 단일 분할 정합성 | 기존 저장본의 요청·종목·유효 종가·분할 진단을 구간별로 확인하고 근거서에 연결. 정규장 종가 범위를 명시하는 공급자 자료가 있으면 함께 기록. 현재 환경에는 저장본과 이 근거서가 없음 |
| `distribution_coverage` / `split_coverage` | 두 공식 표의 알려진4건 및 Form8937의 12-05 분할 | 2025년 전체 분배·분할 목록을 검토한 범위와 출처를 입력 해시에 묶어 기록. 4행 일치나 분할 공지1건만으로 미기록 사건 부재까지 자동 승인하지 않음 |

확인된 해석은 자본이득 0과 KIS 옵션 정의까지다. **주당 기준은 이번에 추가 해소하지 못했다.**
위 명시적 자료가 새로 확보되기 전에는 같은 검색·원장 재실행·가격 재수집을 반복하지 않는다.
사용자에게 KIS 문의·키 전달·전체 원자료 공유를 요구하지 않는다.

기존 달력으로 2025년은 정규 거래일250개, 첫날2025-01-02, 마지막2025-12-31이다.
나중에 자료 조건이 갖춰지면 이 범위를 오프라인 검증할 수 있지만 지금 계산 가능 구간으로 승인한 것은
아니다. 분할 전/후나 배당 없는 짧은 기간도 공통 가격·목록 조건을 우회하지 않는다.
불명확한 사건을 빼서 전체 연간 수익률로 이어 붙이지 않으며, 원래 평가 구간의 변경도 아니다.
