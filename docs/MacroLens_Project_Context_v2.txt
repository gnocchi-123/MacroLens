MacroLens 프로젝트 맥락과 협업 지침
버전: 2.0
작성일: 2026-10-01
언어: 한국어

이 파일의 목적
ChatGPT가 프로젝트의 확정 조건과 설계 상태를 이해하기 위한 참고 자료다. 실행 가능한 코드가 아니다. 상세 계산·검증·보고서 규칙은 계획 v2.0을 참조한다. 사용자 최신 지시, 실제 저장소 상태, 설계 제안을 구분한다.

1. 프로젝트
- 이름: MacroLens / 미국 거시경제 기반 섹터 분석.
- 핵심 산출물: 설명 가능한 점수·검증 프로그램과 주간 보고서.
- 목적: 미국 거시 자료에 따른 섹터 점수가 이후 상대 성과와 연결되는지 검증하고, 근거가 있으면 투자에 활용.
- 장기 목표: SPY 대비 투자 성과 개선. 수익 보장 조건이 아님.
- 경제 전망, 섹터 선택, 비용 반영 투자 성과를 각각 평가.
- 현재 환경만 분석했다면 미래 경제 전망 적중률을 주장하지 않음.

2. 사용자 확정 조건
- 미국 분석 시장으로 제한. 한국·글로벌 확장은 현재 범위가 아님.
- 간단한 코드 작성 가능. Python 경험은 제한적이므로 단계별 설명 제공.
- 코드 작성 도움과 함께 코드 제작 프롬프트도 요청할 예정.
- 기존 ChatGPT 이용 금액은 고정 비용으로 봄.
- 초기 추가 지출 0원 목표. 프로그램이 효과적이면 월 1만~2만 원 추가 지출 의향.
- 이 의향을 즉시 유료 서비스 가입·결제 승인으로 해석하지 않음.
- 추가 운영비는 데이터·개발·실행·저장·선택적 AI API를 합산하는 기본안. 투자금·거래비용·세금은 성과 항목으로 별도 관리.
- 위 세 가지 조건을 다시 처음부터 질문하지 않음.

3. 설계 기본값과 미확정 사항
- Python 핵심 개발, GitHub Codespaces 개발 방향 유지.
- 미국 11개 섹터, 달러 기준, 3개월 주평가·1개월 및 6개월 보조 평가.
- 한국어 Markdown·HTML 보고서, 초기 파일 직접 확인.
- 주간 판단. 조건부 주간 거래를 주실험 후보로, 매주 조정·매월 조정을 비교.
- 월요일 09:00 KST 자료 기준, 09:17 생성 목표는 제안 일정이며 아직 자동화되지 않음.
- 전체 섹터 계수표, 가격 공급자, 검증 기간·합격 기준, 영구 저장처 미확정.
- 저장소·Codespace·API 키·프로그램 구현 상태는 아직 확인되지 않음.
- 개인 투자 위험 한도·세금·원화 환산 기준은 개인화 단계에서 확인.

4. AI의 역할
- 개발 중 ChatGPT의 코드 작성·프롬프트·검토·오류 설명과 프로그램 안의 자동 AI 호출은 별개.
- 첫 버전은 Python 계산과 문장 템플릿만으로 완성. AI API 필수 아님.
- 필요하면 사용자가 보고서를 ChatGPT에 제공해 해설 요청.
- 자동 AI 설명은 후속 선택 기능. 도입 시 요금·포함 범위를 공식 자료로 확인.
- AI가 점수·가격·기여도·출처를 임의 수정하지 않음. 실패 시 템플릿 사용.

5. 데이터 원칙
- FRED·ALFRED 우선 검토. 첫 지표는 INDPRO, UNRATE, CPIAUCSL, DGS10.
- 단위·계절조정·빈도·사용 조건은 구현 시 공식 메타데이터 확인.
- 관측 대상일, 발표일, 이용 가능일, 수집일, 자료 버전 구분.
- 과거 판단에 최신 수정값이나 미래 발표를 넣지 않음.
- 과거 버전이 정확한 장중 발표 시각을 보장한다고 가정하지 않음.
- 시점 자료가 부족하면 한계를 표시하고 엄밀한 과거 검증에서 제외하거나 보수적 지연 적용.
- 월별 값 반복을 새 관측·새 정보로 세지 않음. 정상 미발표와 수집 실패 구분.
- 전월 대비 변화를 시장 예상 대비 변화라고 표현하지 않음.
- ETF 출시일·섹터 변경·공통 검증 기간을 반영. 지수 연구와 실제 ETF 검증 구분.
- 가격 공급자는 미확정. 배당·분할·사용 조건 검증. 조정가격에 배당을 다시 더하지 않음.
- 원본·당시 판단·정정판은 이력을 남기고 덮어쓰지 않음.

6. 점수 모델의 지위
- 경기순환 투자 관점과 일반적인 표준화·가중합에서 착안한 자체 연구 가설.
- 특정 논문에서 검증된 산식·계수를 그대로 가져왔다고 주장하지 않음.
- 60개월, ±3 제한, 계수 -2~+2, 기준점 50은 검증 전 시작값.
- 첫 변환안: 산업생산 전년 대비 증가율, 실업률 3개월 차이의 음수, CPI 전년 대비 상승률, DGS10 28일 차이.
- 각 양수 요인의 경제적 뜻을 명시. 표준화 양수는 과거 기준보다 높다는 의미이지 절대 호황·절대 상승과 동일하지 않음.
- 최신 관측 이전의 유효 관측으로 평균·표본 표준편차를 계산하고 z값을 ±3으로 제한한 뒤 3으로 나눔.
- 창 후보: 월별 60개, 주별 260개, 일별 1,260개. 이력 부족·표준편차 0이면 보류.
- 섹터 점수 = 50 + 50 × Σ(계수×요인) / Σ|계수|.
- 기여도 합 + 50 = 점수. 80점은 상승 확률 80%가 아님.
- 계수를 같은 배수로 키우면 점수가 같음. 실제 수익률 민감도 추정치가 아님.
- 계수마다 영향 경로·출처·반대 근거·적용 한계·버전 기록. 전체 계수는 성과를 보기 전에 동결.
- 코드 확인용 가상 계수와 실제 연구용 계수 구분. 아직 검증된 전체 계수표 없음.
- 첫 버전은 활성 입력 모두 유효할 때 공식 비교 순위 계산. 기존 80% 누락 정규화는 후속 실험으로 이동.
- 정상 발표 주기 안의 값 유지 허용. 지연 한도 초과·핵심 누락 시 공식 순위와 모의 리밸런싱 보류, 기존 보유 손익은 계속 평가.

7. 투자 규칙과 검증
- 기본 비중 1/11에 (점수-평균점수)/50 × 0.05를 더함.
- 합계 1, 개별 0~20% 제약하에서 목표 비중 결정. 세부 산식은 계획 참조.
- W: 매주 목표 조정. M: 매월 첫 미국 거래일 조정. C: 매주 검토, 목표·현재 비중 최대 차이가 2%포인트 이상이면 전체 목표로 조정.
- C는 주실험 후보이며 2%포인트는 미검증 설정. 주간 거래 우위를 확정하지 않음.
- 점수가 같아도 가격 변화로 실제 비중이 달라질 수 있음. 현재 비중으로 판단.
- 레버리지·공매도·현금 타이밍 제외. 항상 주식에 투자하는 실험의 하락 위험 명시.
- 판단 이후 가능한 체결 가격 사용. 연구 기본은 다음 미국 정규장 종가, 지연 시 놓친 가격으로 소급 체결 금지.
- 거래대금당 편도 비용 5/10/25bp는 연구 가정. 실제 요금으로 표현하지 않음.
- 거래비용 차감·개인 세금 전 달러 성과를 기본으로 표시.
- SPY, 대응 일정의 동일 비중, 단순 가격 추세와 비교.
- 순위 관계, 상·하위 섹터 차이, 비용 차감 수익률·낙폭·회복·회전율 평가.
- 시간순 개발·검증·최종 평가. 아직 확정되지 않은 3개월 성과를 훈련에 넣지 않음.
- 겹치는 주간 3개월 성과를 독립 사례로 세지 않음.
- 시도한 모델과 실패 결과도 기록. 최종 평가를 보고 수정하면 새 독립 평가가 필요.
- 짧은 모의 운용은 장기 초과수익 증명이 아님.

8. 스트레스 테스트 범위
- 실제 충격기를 전체 성과에서 제외하지 않음.
- 최대 낙폭·회복기간, 비용 증가, 한 거래일 지연, 자료 누락, 소수 설정 변경은 최소 검증.
- 복잡한 가상 거시·상관·유동성 충격 시뮬레이션은 후속.
- 점수 모델만으로 특정 금리 충격에 따른 수익률 손실을 산출하지 않음.
- 가상 시나리오는 예측이 아님. 사후 사건 날짜를 과거 거래 신호로 쓰지 않음.

9. 보고서 연결
- 이번 주·전주·4주 전·13주 전 비교를 핵심 기능으로 포함.
- 점수·순위·기여도·자료 상태·판단 변경 이유·모의 거래 여부 표시.
- 새 발표, 과거 수정, 기준창 변화, 모델 변경, 자료 상태 변화 구분.
- 요인 기여도 변화 합이 점수 변화와 일치해야 함.
- 분해 순서와 재계산 여부를 표시. 경제 인과효과라고 해석하지 않음.
- 모델 변경 시 구모델과 신모델 연결 계산 가능 여부 확인. 비교 불가능하면 이유 표시.
- 전주 누락 시 전주 비교 없음 표시. 마지막 가용 보고서와 비교할 때 실제 간격 표시.
- 동일 주 정정판을 새 주로 세지 않음. 4주·13주 기록 부족 시 표시.
- 과거 판단은 그대로 보관. 평가 만기 전 결과는 중간 경과로 표시.
- 경제 전망의 최초 발표값 채점과 수정값 평가는 구분.
- AI 기억에 의존하지 않고 저장된 결과와 run_id로 보고서 재생성.

10. 개발 순서
1) 환경 확인과 네 지표 작은 실행 예제.
2) 과거 시점·원본·실행 이력·전주 비교.
3) 계수 근거서·동결·11개 섹터 점수.
4) 가격·W/M/C·비교 전략·최소 위험 검증.
5) 주간 보고서의 추세·변화 원인·만기 평가.
6) 영구 저장·복구·중복 방지·자동 실행.
7) 실시간 모의 운용.
8) 증거와 비용을 보고 확장 판단.

11. 협업 규칙
- 한국어, 목적·파일·코드·명령·정상 결과·오류 확인 방법을 연결해 설명.
- 최신 패키지·API·요금은 구현 시 공식 자료 확인.
- 코드 작성 요청은 가능한 범위에서 직접 구현하고 검증.
- 기존 계정·저장소가 있으면 재생성을 요구하지 않고 확인 후 이어서 사용.
- API 키·비밀번호를 대화에 붙여 넣게 하지 않고 환경변수·Secrets 안내.
- 테스트하지 않은 결과와 가상 숫자를 실제 결과로 표현하지 않음.
- 유료 기능은 필요·비용·대안을 제시하고 도입 결정 확인.
- 이메일·메신저·주문은 별도 요청 없이 설정하거나 실행하지 않음.
- 계획 v2.0의 단계별 코드 제작 프롬프트를 출발점으로 사용.

12. 현재 상태
- 완료: 사용자 피드백 반영 계획 v2.0과 이 맥락 파일 작성.
- 미확인/미완료: 저장소·Codespace 상태, 프로그램 구현, 실제 수집, 계수 검증, 백테스트, 예약 실행, 모의 운용.
- 다음 구현 작업: 기존 저장소·환경 상태 확인 후 네 지표의 작은 동작 버전.
- 이번 문서 작성 자체를 개발·자동화 완료로 간주하지 않음.
