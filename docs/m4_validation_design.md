| 단위 | 메타데이터 적용 시작 | 적용 종료 |
| --- | --- | --- |
| Index 2012=100 | 2015-07-21 | 2021-05-27 |
| Index 2017=100 | 2021-05-28 | 조회 페이지의 최신 vintage 2026-09-18 |

이는 **관측 대상일**이 아닌 **자료 버전의 메타데이터 유효기간**이다.
2021년 6월 vintage 안의 오래된 관측값은 해당 vintage의 단위·수정 이력을 따른다.
2017년 등의 원래 관측 날짜만 보고 그 값을 자동 배제할 이유는 없다. 반대로 이전 vintage의
단위를 무시하거나 오늘의 값으로 바꿔 긴 실험 기간을 만들 수는 없다.
2021-06-07을 후보 시작일로 두는 이유는 이 제약이며, 성과를 살펴본 결과가 아니다.
이후 모든 주가 통과한다는 뜻도 아니므로 vintage별 메타데이터·준비 관측량을 사전 조사해야 한다.

**날짜 단위 vintage를 이용하는 제한적 후향 연구**, `strict_point_in_time=false`를 유지한다.
판단 시점·관측 대상일·이용 가능 시점·실제 수집 시각·vintage 날짜를 각기 기록한다.
현재 수정된 관측을 날짜만 잘라 과거 입력으로 쓰지 않는다. 현재의 과거 vintage 조회는
당시 저장했던 자료를 재현하는 것과 다르며, 저장 실행 replay는 외부 API 없이 한다.
M2/M3의 전일 vintage 및 보수적 가용성 규칙을 유지해도 정확한 장중 발표 시각까지 증명되지 않는다.
실제 FRED API 실행 성공과 엄밀한 과거 정보집합 복원을 구분한다.

## 3. 가격 범위와 자료 적격성

평가 후보는 2021-06-07~2026-09-30. 가격 준비 요청은 2020-06-01부터다.
KIS의 조회 기준일·연속조회와 범위 포함 여부를 공식 계약 및 실제 응답으로 확인한다. Yahoo 형태 입력의 배타적 종료값 2026-10-01을 KIS에 자동 적용하지 않는다.
현재 확보된 것은 배당 대조원이며 **일별 가격 공통 범위와 준비 범위는 미확정**이다.
달력상 예상 1592일을 실제 확보 행 수나 유효 평가 표본 수로 쓰지 않는다.

자료 관문은 XLC·XLK·SPY 3종, 그 후
XLE·XLB·XLI·XLY·XLP·XLV·XLF·XLK·XLC·XLU·XLRE·SPY 전체다.
11개 섹터의 가격·거시 입력·만기가 모두 유효한 공통 표본을 주평가로 제시하고 탈락 이유를 센다.
자료가 부족하면 성과를 보기 전에 기간을 재검토해 기록한다. 결측을 메우거나 특정 섹터를
유리하게 제거하지 않는다. ETF 상장 이전을 지수나 다른 ETF로 이어 붙이지 않는다.

과거 실제 운용 ETF를 평가하며 현재 보유 종목으로 과거를 재구성하지 않는다.
XLC의 늦은 설정·상장, 섹터 분류 개편, 2025년 분할은 자료 검수와 해석의 제약이다.
2022~2023년 가설·분류 개편 시점은 사전에 표시할 수 있으나 수익률을 보고 경계를 옮기지 않는다.
최신 조정가격은 사후 수정될 수 있다. 같은 출처·버전·정의로 동결한 원본 해시를 실험에 연결하고
나중 수정 다운로드는 새 버전으로 기록한다. 조정가격 절대값은 당시 체결가격으로 쓰지 않는다.

## 4. 시간순 분리와 만기 표본 — 제안

첨부 초안의 다음 분리는 사용자 최종 승인을 받은 실험 설정이 아니다.
자료 적격성 확인 후 성과 계산 전에 확정할 후보로 남긴다.

| 구간 | 후보 기간 | 목적 |
| --- | --- | --- |
| 준비 | 가격 2020-06-01부터, 거시는 각 판단에 필요한 과거 vintage 이력 | 추세·M3 변환·표준화 준비. 성과 표본에서 제외 |
| 개발 | 2021-06-07~2022-12-31 | 계산·예외·원장 검증. 계수 학습·최적화 없음 |
| 검증 | 2023-01-01~2023-12-31 | 동결 설계의 작동 확인 |
| 후향 평가 | 2024-01-01~2026-09-30 | 규칙 확정 후 한 번에 실행·보고 |

무작위로 날짜를 섞지 않는다. 진입과 만기가 모두 같은 구간 안에 있는 표본만 그 구간의
점수 평가에 넣는다. 최대 6개월 만기가 경계를 넘는 표본을 제거하며 제거 수를 만기별로 공개한다.
2026-09-30까지 만기가 오지 않은 표본은 `미성숙`으로 남긴다. 0%나 짧은 기간 수익률로 채점하지 않는다.
1·3·6개월 비교는 각각의 성숙 표본과 세 만기가 모두 성숙한 공통 표본을 구분한다.

판단 슬롯은 기존 한국시간 주간 슬롯을 이용한다. 구체적 가격 진입 시각 후보는
**판단 이후 첫 미국 정규장 종가**, 추가 한 거래일 지연을 민감도 점검으로 둔다.
월말·휴일·서머타임은 거래소 달력으로 처리한다. 같은 날이라도 판단 이전 가격에는 진입하지 않는다.
1·3·6개월은 고정 21·63·126 거래일 대신 달력 월 만기 후보를 쓰되, 해당 월 말일을 넘으면 말일로
줄이고 휴장일은 다음 미국 거래일로 옮긴다. 이 만기·체결 규칙은 구현 전 승인·동결 대상이다.

모델은 2026년에 설계되었다. 과거 구간을 분리해도 진정한 미래 검증으로 바뀌지 않는다.
공식 상품 조사 중 일반 상품 성과 표에 노출될 수 있었으며 완전한 맹검이었다고 주장하지 않는다.
M4 전략 수익·순위상관·전략 순위는 이번에 계산하지 않았다.

## 5. 점수의 설명력·예측 관계 평가 — 제안

주평가 만기는 **3개월**, 1개월과 6개월은 보조다.
매주 유효한 11개 섹터 점수 순위와 이후 섹터 총수익률 순위의 Spearman 상관(Rank IC)을 제안한다.
이는 “높은 점수 순서와 높은 이후 성과 순서가 얼마나 같은가”를 나타낸다.
상대 성과는 같은 주·같은 만기의 11개 섹터 동일 비중 평균 대비로 정의할 후보다.
모든 섹터에 같은 평균을 빼면 순위는 같으므로 절대·상대 Rank IC를 독립적인 발견 두 개로 세지 않는다.

함께 제안할 요약은 상위·하위 점수 바스켓 차이와 가격 추세 신호의 같은 만기 IC다.
M3의 평균 순위를 유지하며 모두 동점이면 IC를 정의 불가로 기록한다. 상위 3자리 경계에 동점이면
남는 비중을 동점 전체에 균등 분배하는 초안 규칙을 검토한다. GICS 표시 순서로 승자를 고르지 않는다.
가격 결측·거시 held·모두 동점·만기 미성숙을 각각 세고 좋은 주만 추려 통계를 내지 않는다.

매주의 3개월 수익률은 대부분의 가격 경로가 겹친다. 11개 섹터 역시 같은 시장 위험을 공유한다.
따라서 **주 수 × 11을 독립 표본 수로 세지 않는다**. 제안은 다음과 같다.

- 한 주의 11개 섹터 단면을 묶은 주간 IC 시계열로 분석한다.
- 달력의 연속 주 블록을 재표집하는 block bootstrap으로 불확실성 구간을 산출한다.
  결측 주를 압축해 실제로 인접하지 않은 주를 이어 붙이지 않는다.
- 기본 블록 길이는 가장 긴 만기를 고려한 26주, 13·52주는 민감도 후보다.
  반복 횟수·난수 시드·유효 블록 최소 수는 성과를 보기 전 추가 동결한다.
- 겹치지 않는 만기 간격 표본을 보조 확인하되, 출발 주가 유리한 경우만 택하지 않는다.
  달력 주 수·유효 주 수·제외 수·블록 수를 함께 보고한다.

짧은 역사에서 불확실성 구간이 넓으면 ‘자료 부족/불확실’로 결론 낼 수 있어야 한다.
첨부 초안의 **IC 0.05, 연율 상대성장 0.5%, 최소 표본 수**는 미승인 제안이다.
코드의 합격 기준·기본 설정으로 넣지 않았다. 여러 보조 기간·거래 규칙을 독립적인 확증으로 세지 않는다.

## 6. 이후 투자 효용 비교 — 아직 구현하지 않음

점수의 이후 상대 성과 관계를 먼저 보고, 별도의 투자 규칙을 평가한다.
가격 조정·배당 재투자의 정의는 [자료 검수서](m4_data_audit.md)의 두 산식 차이를 확인한 후 동결한다.
현재 Adj Close 비율에 현금 배당을 다시 더하지 않는다. 원장 방식이면 권리·지급·재투자 시점을 구분한다.

| 비교 | 목적 | 해석 한계 |
| --- | --- | --- |
| 11개 섹터 동일 비중 | 같은 투자 대상·시기에서 거시 점수로 비중을 달리한 효과 확인 | 대응하는 W/M/C 일정·거래비용을 같이 적용해야 공정함 |
| 가격 추세 | 거시 정보 없이 가격 이력만 이용하는 대안과 비교 | 12개월 중 최근 1개월 제외(12–1), 상위 3개 균등 비중은 제안. 집중도 차이를 거시 정보 효과로 단정 못함 |
| SPY 매수 후 보유 | 미국 대형주 시장에 단순 투자했을 때의 기회비용·위험 비교 | 섹터 동일 비중과 시장 가중치가 달라 SPY 대비 성과만으로 거시 판단의 타당성 판정 불가 |

프로젝트 계획의 목표 비중 후보 `u_s = 1/11 + 0.05 × (S_s - 평균점수)/50`와
합계 1·섹터별 0~20% 제약도 **검증 전 연구 규칙**이다. 이번에 확정·구현하지 않는다.
제약을 적용하고 단순 재정규화해 상한을 다시 깨는 방식은 피한다. 계수 최적화와 구별한다.

- **C(조건부 주간)**를 주전략 후보로 둔다. 매주 판단하되 목표와 현재 비중 차이가 클 때만 거래해
  반응 속도와 거래비용을 함께 관리하려는 가설이다. 성과 우월성을 알고 고른 것이 아니다.
- **W(매주)**는 빠른 반영의 효과·회전율 비용 비교, **M(매월)**은 단순 월간 실행과의 비교다.
  M은 해당 체결 전에 확정된 최근 주간 점수만 이용한다.
- C의 `max |목표−현재| ≥ 2%p`는 기존 계획의 시작 후보다. 최종 승인·최적 기준이 아니다.
  가격·배당·현금 때문에 달라진 현재 비중을 써야 하며 순위 변동만으로 거래하지 않는다.
- 동일 비중도 같은 일정·이탈 규칙으로 비교한다. SPY에도 최초 매수 비용을 반영한다.
  최종 구간 결과를 본 뒤 W/M/C 중 가장 좋았던 것을 사전 주전략인 것처럼 바꾸지 않는다.

최소 점검 제안은 거래비용 편도 5·10·25bp(1bp=0.01%p), 한 미국 거래일 추가 지연,
최대낙폭(고점에서 가장 크게 하락한 폭), 회복기간·변동성·회전율·총 비용이다.
기본 비용 선택·매수/매도 거래금액 정의·수수료와 슬리피지(예상가와 체결가의 차이) 포함 범위는
구현 전 동결한다. 비용을 상쇄하려고 이미 가격에 반영된 ETF 운용보수를 이중 차감하지 않는다.
소수 주식·현금·세금 가정, 점수 보류 시 기존 보유 유지/신규 거래 금지 규칙도 사전 확정한다.
가격 결측을 전일 가격으로 덮어 매매 가능한 것으로 만들지 않는다.

## 7. 재현·미래정보·사후 선택 제한

후속 실험은 모델 설정 해시, Git 코드와 dirty 상태, 판단별 macro run_id,
가격 audit ID·원본 해시·수집 시각·버전, 달력 버전, 실험 설계 버전·제외 사유를 연결해 보존한다.
수집 원본·검사 결과·수정 이유를 별도로 저장하며 새 수집이 과거 기록을 덮어쓰지 않는다.
달력이나 가격 공급자 수정도 새 버전으로 비교하고 과거 결과에 조용히 섞지 않는다.

미래 관측·미래 수정치·판단 이후 점수·과거 구간 경계를 넘어가는 만기 결과로 이전 규칙을 정하지 않는다.
추세도 판단 시점에 이용 가능한 가격만 사용한다. 현재 조정가격으로 과거 가격 수준을 판단하지 않는다.
후향 결과를 읽고 새 가설을 만들면 새 연구 ID와 변경 이유를 남긴다. 동결한 M3 v1은 그대로 보존한다.
R-001 수준·변화·가속도 추가는 [후속 연구 목록](research_backlog.md)에 남긴다.

**전향 기록**은 앞으로 실제 시점마다 쌓는 입력·점수·선택 기록이다. 후향 평가와 별도 원장으로
관리하고 미래에 만기가 온 뒤 평가한다. 과거 vintage를 지금 조회해 만든 실행을 당시의 전향 기록으로
표시하지 않는다. 이번에는 자동 실행을 구현하지 않으며 사용자가 이후 시작일·운영 방식을 검토한다.
