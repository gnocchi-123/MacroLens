# MacroLens 후속 연구 아이디어

이 문서는 현재 모델에 바로 적용하지 않을 연구 질문을 보존한다. 등록은 구현·채택·예측력 검증 완료를 뜻하지 않는다. 각 아이디어는 기존 모델과 비교할 실험으로 구체화한 후 채택·보류·기각을 결정한다.

## R-001. 지표의 수준·변화·가속도를 구분해 사용하기

- 제안일: 2026-10-10
- 제안자: 사용자
- 상태: 후속 연구 후보, 미구현
- 검토 시점: M3 검수와 M4 기본 모델 평가 후. 필요한 데이터 정의는 그 전에 검토 가능.
- 현재 모델: `macro-sector-hypothesis-v1` 유지. 이 문서로 계수·요인 정의·설정 해시를 변경하지 않는다.
- 연결: [계획 4.2절](macro_sector_project_plan_v2.md#42-거시-요인-계산), [현재 계수 근거서](model_card.md), [동결 기록](m3_freeze.md).

### 사용자 제안과 연구 질문

실제 지표의 값뿐 아니라 지표가 얼마나 변했는지를 함께 고려할 필요가 있는가?

예를 들어 금리가 1%에서 2%로 오른 경우와 5%에서 6%로 오른 경우는 모두 +1%포인트지만 도달한 수준은 다르다. 같은 변화 폭을 같은 신호로 처리하는 현재 방식에 수준 정보를 더하면 유용한 차이를 포착할 수 있는지 검증한다. 이 예시는 가상이며 어느 경우가 특정 섹터에 더 유리하다는 결론을 전제하지 않는다.

**실제 자료인지 여부와 입력 형태는 서로 다른 구분이다.** 실제·합성은 데이터 출처이고, 수준·변화·가속도는 그 자료를 계산에 사용하는 방식이다. 현재 모델도 실제 FRED 자료의 변화율·차이를 사용할 수 있다.

### 현재 이미 반영하는 것

| 요인 | v1의 표준화 전 입력 | 현재 빠져 있는 별도 정보의 예 |
| --- | --- | --- |
| 성장 | INDPRO 전년 대비 증가율 | 최근 증가율이 더 높아지는지 낮아지는지 |
| 고용 | 실업률 3개월 차이의 음수 | 실업률 자체의 수준 |
| 물가 | CPI 전년 대비 상승률 | 상승률이 둔화·가속하는 정도 |
| 금리 | DGS10의 28개 달력일 차이 | 10년 명목금리 자체의 수준 |

따라서 이 아이디어는 “변화를 처음 도입”하는 작업이 아니라 **현재 선택한 변환값에 다른 정보가 추가 가치를 주는지** 살펴보는 작업이다. 계획 v2 4.2절의 “수준·변화·가속도는 별도 실험” 원칙을 구체화한다.

### 용어와 후보 정의

| 구분 | 뜻 | 검토용 예시 |
| --- | --- | --- |
| 수준 | 판단 시점의 상태 | 실업률 U, 10년 금리 y |
| 변화 | 일정 기간의 차이·증가율 | U_m − U_(m−3), y_d − y_d0, 산업생산 전년 대비 증가율 |
| 가속·둔화 | 변화율 또는 변화 폭이 이전보다 커지거나 작아짐 | 물가상승률 π_m − π_(m−3), 산업생산 증가율 g_m − g_(m−3) |

m은 최신 이용 가능한 월별 관측, d는 최신 일별 관측이다. d0는 d−28일 이하 최신 유효 관측일이다. 위 기간은 연구 후보를 설명하는 예시이며 채택된 추가 설정이 아니다.

물가의 π는 `100 × (CPI_m / CPI_(m−12) − 1)`이다. π의 차이는 %포인트로 표시한다. CPI 지수 자체의 수준, 물가상승률 수준, 물가상승률의 변화는 구별한다. 산업생산도 원지수 수준과 증가율을 구별한다.

시간에 따라 추세적으로 높아지거나 기준연도에 의존하는 원지수 수준을 무조건 추가하지 않는다. 경제적으로 해석할 수 있는 상태 변수인지 먼저 판단한다. 표준화했다고 장기 추세 문제가 자동으로 해결되는 것은 아니다.

보고서의 전주 요인값 차이도 그대로 가속도 입력으로 쓰지 않는다. 새 발표가 없어도 자료 수정이나 표준화 기준창 변화로 차이가 생길 수 있기 때문이다. 먼저 원자료의 시간 간격에 맞춰 변환을 정의하고, 이후 과거 자료로 표준화한다.

### 기대하는 개선과 실패 가능성

- **추가 정보 가능성:** 높은 물가가 둔화하는 상황과 낮은 물가가 가속하는 상황처럼, 현재 값 하나로 구분하기 어려운 조합을 표현할 수 있다.
- **중복 반영:** 같은 지표에서 여러 입력을 만들면 사실상 같은 정보를 반복 가중할 수 있다. 입력을 많이 만든 요인의 비중이 자동으로 커지지 않도록 해야 한다.
- **노이즈·시차:** 짧은 기간 변화는 수정치·기저효과·일시적 변동에 민감할 수 있다. 월별 값을 주별로 반복한다고 새 정보가 생기지는 않는다.
- **고정 부호의 한계:** 금리 수준이 높다고 언제나 불리한 것은 아니다. 비선형·상호작용을 설명해야 하는지 검토하되 처음부터 복잡한 규칙을 대량 도입하지 않는다.
- **과적합:** 기간·조합·가중치를 많이 시도해 과거 최고 성과만 고르면 성능을 과장할 수 있다. 실패한 후보도 기록한다.

### 나중에 진행할 최소 실험안

1. **기준 모델 고정:** v1의 계수·변환·데이터 규칙과 평가 결과를 보존한다.
2. **추가 입력 하나 선택:** 예를 들어 금리 수준 추가 또는 물가상승률의 변화 추가 중 하나부터 연구한다. 후보·경제적 경로·부호·기간·표준화 창을 성과 확인 전에 기록한다.
3. **비중 통제:** 기존 요인과 신규 입력을 각각 표준화하되, 같은 경제 축 안에서 결합하는 방안을 우선 검토한다. 예: 금리 축을 수준·변화로 나누더라도 축 전체의 비중을 먼저 고정한다. 가중 평균이나 별도 계수 중 어느 방식을 쓸지는 별도 설계하며 50:50을 정답으로 전제하지 않는다.
4. **시점 일관성:** 당시 이용 가능한 vintage와 발표·이용 시점 규칙을 적용한다. 최신 수정값으로 과거 가속도를 다시 만들어 당시 신호로 가장하지 않는다. 기존 시점 자료의 한계 표시를 유지한다.
5. **공정한 비교:** 준비 기간을 포함해 공통으로 유효한 기간·섹터·가격·체결·비용·거래 규칙을 맞춘다. v1과 추가 입력 후보를 비교하고 순위상관, 상·하위 차이, 비용 반영 성과와 불확실성을 본다.
6. **추가 가치 분리:** 새 입력을 제외한 결과와 비교하고, 단순 가중치 변경 때문인지 정보 추가 때문인지 구분해 본다. 특정 시기·섹터에만 결과가 집중되는지도 확인한다.
7. **새 평가 확보:** 겹치는 주간 3개월 성과의 의존성을 처리한다. 이미 본 M4 최종 평가 구간은 새 후보의 독립 최종 평가로 재사용하지 않는다. 별도 미열람 구간이나 향후 기록으로 확인한다.
8. **채택·보류·기각:** 개선이 안정적이고 해석·운영 비용을 정당화할 때 새 모델 버전으로 채택한다. 개선이 불확실하면 v1을 유지한다. 모델 변경 효과와 경제 입력 변화는 보고서에서 구분한다.

### 착수 전에 결정할 사항

- 어떤 지표·입력 하나를 먼저 추가할 것인가?
- 원래 값의 수준인가, 증가율의 수준인가? 변화 간격과 단위는 무엇인가?
- 추가 입력의 양수는 무엇을 뜻하며 기존 축의 방향과 어떻게 맞출 것인가?
- 기존 입력과의 중복 및 경제 축 전체 비중을 어떻게 통제할 것인가?
- 비교 기간·후보 수·평가 기준·독립 평가 자료는 무엇인가?

현재 판단: **기록하고 나중에 검증할 가치가 있는 제안이다. 효과는 아직 알 수 없으며 M3의 필수 작업으로 확대하지 않는다.**
